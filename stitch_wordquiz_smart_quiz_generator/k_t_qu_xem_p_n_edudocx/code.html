C# được biên dịch sang mã trung gian Common Intermediate Language (CIL/MSIL) theo chuẩn CLI của Microsoft. Sau đó, khi ứng dụng thực thi trên máy trạm hoặc máy chủ, Common Language Runtime (CLR) sử dụng bộ biên dịch JIT (Just-In-Time) compiler để dịch mã CIL thành mã máy nguyên bản (native machine code). Do đó C# không phải là ngôn ngữ thông dịch thuần túy như JavaScript hay Python.

ASP.NET Core là framework mã nguồn mở của Microsoft, chạy đa nền tảng (Windows, macOS, Linux) để xây dựng ứng dụng web hiện đại kết nối đám mây, RESTful APIs và microservices. Database trong hệ sinh thái .NET thường được quản trị bởi SQL Server, PostgreSQL hoặc ORM Entity Framework Core, không phải chính ASP.NET Core.
